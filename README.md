# Ibadan Admission Compass

Build a beautiful, original, responsive web application called University of Ibadan Admission Assistant, a chatbot that helps prospective students access admission information.

UI/UX: Create a unique, premium university-inspired design that looks professionally crafted, not like a generic AI dashboard or ChatGPT clone. Use deep navy/indigo, warm ivory, and subtle crimson accents, elegant typography, generous whitespace, refined cards, subtle animations, and distinctive academic-inspired visuals. Make it visually impressive on desktop and mobile.

Core features:

Beautiful welcome page with a hero section, short introduction, and “Start Conversation” button.

Interactive chatbot with message bubbles, typing indicator, input field, send button, and suggested questions.

Admission information categories: Requirements, Programmes, Application Process, Screening, UTME/Direct Entry, Fees, and FAQs.

Searchable information cards and suggested questions.

Responsive navigation and mobile-friendly chat layout.

Technology: React, TypeScript, and Tailwind CSS.

Architecture: Frontend only. No backend, database, paid APIs, API keys, or authentication. Use modular local JSON files for admission information, with fields for questions, answers, categories, sources, and update dates. Use clearly labelled placeholders wherever verified University of Ibadan information is unavailable. Never fabricate official admission facts.

Keep the code clean, modular, and easy to extend with browser-based NLP and Transformers.js semantic search later. Basic chat interactions should work using the sample knowledge base.

Priority: Exceptional, distinctive UI/UX and a functional first version. Do not overengineer or implement advanced AI yet. Avoid generic templates, excessive gradients, and unnecessary features.
